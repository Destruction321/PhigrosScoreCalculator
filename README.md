# Phigros算分器，助力你打出114514分（？

一个用 C 写的 Phigros 控分小工具，闲得没事就改改。

输入谱面的音符总数和你想打出的分数，程序会帮你寻找对应的 **Perfect、Good 和 Max Combo** 组合。

至于手能不能照着打出来，那是另一个项目了。

## 能干什么

- 根据音符总数和目标分数，查找判定与最大连击的组合。
- 逐个查看方案、每次查看 10 个，或者一口气全部输出。
- 选择一个方案查看，也可以把全部方案保存成文本文件。
- 找不到方案时告诉你：这个分数确实有点为难这张谱了。

算的是控分方案，不是 RKS。也不会自动帮你打歌，手还是得自己长。

## 怎么用

1. 启动程序，按回车开始。
2. 输入谱面的音符总数，范围为 `1～5000`。
3. 输入目标分数，范围为 `0～1000000`；这一步输入 `-1` 可以重新设置音符数。
4. 按屏幕提示查看、选择或导出方案，输入选项后按回车确认。

导出时直接回车使用默认文件夹，文件会保存在当前工作目录的 `solutions/default/` 下，文件名类似 `1000notes,goal=900000.txt`。也可以按提示指定 `solutions/` 下的文件夹。

程序对几个特殊目标分数有非常朴素的建议：

| 目标分数  | 程序的建议                           |
| --------- | ------------------------------------ |
| `0`       | 放置即可。躺平也是一种解法。         |
| `685000`  | 全部 Good 即可。另一种意义上的精准。 |
| `1000000` | 获得 AP 即可。说得好，下次别说了。   |

## 编译运行

使用支持 C17 的 C 编译器即可。终端需要支持 UTF-8 中文和 ANSI 转义序列，否则界面可能会开始表演乱码艺术。

以 Windows 下的 GCC / MinGW-w64 为例，在项目根目录打开 PowerShell：

```powershell
gcc -std=c17 -Iinc/core -Iinc/io/in -Iinc/io/out -Iinc/utils main.c src/core/*.c src/io/in/*.c src/io/out/*.c src/utils/*.c -o PhigrosScoreCalculator.exe -lm
.\PhigrosScoreCalculator.exe
```

如果中文显示乱码，可以先执行 `chcp 65001`，再运行程序。

## 想看看怎么算的

代码里的核心计分关系可以写成：

```text
分数 = (900000 × Perfect + 585000 × Good + 100000 × Max Combo) / 音符总数
```

程序根据这个关系和判定、连击的约束寻找方案。输出的是数量组合，具体在哪里断连、哪个音符打 Good，还得自己安排。

更详细的公式推导和算法说明放在 [MORE_DETAILS.md](docs/MORE_DETAILS.md) 里。想认真研究可以看，不想看也完全不影响使用。

头文件怎么拆、内存归谁管，另见 [CODE_STRUCTURE.md](docs/CODE_STRUCTURE.md)。运行回归测试可以执行 `python tests/run_tests.py`（需要 Python 和 GCC）。
